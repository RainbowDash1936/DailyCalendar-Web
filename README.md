# 每日计划网页版（PWA）

这是原生 iOS 版之外的第二个方案。它不需要 Mac、不需要 Sideloadly、不需要 Apple Developer 账号，也不需要每 7 天续签。

## 能实现的功能

- 全年 365 / 366 天打卡热力图
- 每日习惯和区间任务
- 今天页面显示当天所有有效任务
- 批量粘贴任务并识别日期、区间、重复星期和提醒时间
- 任务管理、归档、编辑和删除
- 打卡动画
- 浅色 / 深色主题、整体配色和自定义强调色
- JSON 备份和恢复
- 番茄钟
- 添加到 iPhone 主屏幕后，可像 App 一样打开
- 离线缓存，断网后仍可使用已缓存页面

## 网页版的提醒边界

网页版可以使用浏览器通知，但当网页被系统完全关闭后，不能像原生 App 一样保证后台定时提醒。当前实现是：

- 网页在前台或主屏幕窗口中打开时，按提醒时间检查未完成任务
- 番茄钟完成时发送浏览器通知
- 可在“设置”中点击“测试提醒”验证通知权限

如果需要严格的每日后台提醒，需要原生版本或把任务导出到 iOS 日历。

## 如何部署

网页版需要放在 HTTPS 网站上，iPhone 才能把它添加到主屏幕并启用离线缓存。最简单的方式是使用 GitHub 免费托管：

1. 注册或登录 GitHub。
2. 新建一个 Public 仓库，名称例如 `DailyCalendar-Web`。
3. 把本目录中的全部文件上传到仓库。
4. 打开仓库的 `Settings -> Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/ (root)`。
7. 保存后等待 GitHub 生成网址，例如：

```text
https://你的用户名.github.io/DailyCalendar-Web/
```

8. 用 iPhone Safari 打开这个网址。
9. 点击 Safari 底部的“分享”按钮。
10. 选择“添加到主屏幕”。
11. 从主屏幕打开“每日计划”。

## 数据位置和备份

网页版的数据保存在当前网站域名的浏览器本地存储中。

因此：

- 换网址、换域名或清除 Safari 网站数据后，任务可能消失
- 建议定期在“设置 -> 备份与恢复”中导出 JSON
- 在 iPhone 主屏幕覆盖更新网页版本时，不要删除网站数据

## 与 Windows 版的数据关系

网页版和 Windows 版默认各自独立保存。网页版支持导入 / 导出 JSON，可以在设置页面手动迁移数据。

## 目录说明

- `index.html`：页面结构
- `styles.css`：桌面端和 iPhone 主屏幕界面
- `app.js`：日历、任务、打卡、导入、主题和番茄钟逻辑
- `icons.js`：本地图标
- `manifest.webmanifest`：PWA 配置
- `sw.js`：离线缓存
- `pwa.js`：注册离线缓存
- `icon-192.png` / `icon-512.png`：主屏幕图标
- `apple-touch-icon.png`：iPhone 主屏幕图标
